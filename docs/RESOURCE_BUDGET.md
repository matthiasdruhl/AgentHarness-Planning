# Resource and spend budget

Track Meta inference separately from coding-agent execution and hosting. Before running paid calls, record participant credit balance, expiry, provider/model access and hard caps, not guessed dollar totals.

Set per-run ceilings for wall clock, agent iterations, token consumption, concurrent sandboxes and disk/network resources. Default max one experiment pair at a time; freeze optional repeats if credit budget tight. Log observed usage and unavailable counters as null, never zero. If credits exhausted, switch to recorded demo with provenance label; don't promise numerical savings without data.
