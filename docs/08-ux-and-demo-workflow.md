# 08 — UX and journey

Single coherent 4-step web journey, accessible and honest:
1. **Intent:** type roadmap statement; Muse returns **suggestions**; user confirms or dismisses, with provenance.
2. **Foresight:** show A/B module boundaries, graph/blast-radius heatmap, scenario list, risk assumptions, upfront cost; call scores estimates.
3. **Experiment:** split screen measured A/B traces and independent acceptance checks, with both using same verifier. Permit recorded playback only if labeled.
4. **Certificate:** show which architecture performed better under each scenario, where it lost, unknowns, checks, costs, model version, report export.

Display a prominent **estimated vs measured** legend; don't display a run animation as live when replaying stored output. Empty/error/loading and provider-offline states. High contrast, keyboard controls, text equivalents for graphs, concise export JSON.
