# ForeCode — promotion gates and kill switches for competitive features
**Prepared:** October 27, 2026. This is the decision tree used to choose what Codex may work on **after** essential functions. It neither authorizes agent execution nor creates new milestone IDs. **Nov 2, 2026 is a hard feature freeze**; Nov 4 at 9 PM Eastern is submission cutoff.

## P0: prerequisite chain — do not trade off
**P0 safety/provenance:** public post-kickoff code, organizer eligibility and rights addressed; developer-local sandbox does not expose secrets/host/oracle; *real agents require independent fresh authorization* and spend/egress/custody approval.  
**P0 Meta:** eligible genuine Meta hypothesis and falsifiable self-challenge, explicit user consent/provenance, strong input/output schemas and bounded cost. A mock or Muse Code used to author code is not qualifying proof.  
**P0 research + demo:** booking fixture, protected evaluator, real source-backed (limited) Atlas, read-only authenticated evidence or honestly absent state, short public browser flow, 3-minute recording and clean public links. One controlled A/B is P0 only to support **measured architecture improvement**; without an authorized run the product must remain truthful and submit only what actually works.

Before *any* stretch ticket, owner records: source SHA, actual P0 gates passing, no unresolved higher-priority defects, safe execution/credits if needed, remaining event calendar time, expected judge-visible payoff **inside 3 minutes**, and rollback branch. Only one stretch promotion at a time.

**Automatic no-go:** if real Meta transport is still mocked, if the first usable public demo is broken, if primary experiment is unverified, if protected data would be exposed, or if any optional effort would extend past Nov 2. One optional feature does not make another mandatory.

## Hard calendar decisions

**Oct 27–28:** prioritize Meta live path, independent real-agent review, source-backed Atlas; prepare actual preregistered A/B protocol. Any unreviewed real-agent run is **BLOCKED**.  
**Oct 29:** P0 vertical slice must work in clean browser; recorded/absent proof is accurately labeled. If missing, freeze UI feature requests and finish this first.  
**Oct 30:** first *safe* matched A/B; first video capture. Without both, **no new extra provider, SCBench, adaptive experiments or cosmetic graph work**.  
**Oct 31:** review pair quality and time; decide whether C and modest Time Machine add tangible clarity. Hard cap optional work; finish draft video.  
**Nov 1:** integrate only validated optional packages; 3-minute walkthrough must complete, source/video/receipt claims reconciled. Cut unfinished optional PRs.  
**Nov 2:** hard feature freeze. Deployment, consistency checks, accessibility, security and video.  
**Nov 3:** record, rehearse and fix actual blockers; no new experimental ideas.  
**Nov 4:** final public smoke, verify eligibility, paywall/privacy constraints, submit early and preserve confirmation before **9:00 PM ET**.

## Safe fallback ladder
1. **Gold:** eligible real Meta + protected matched A/B + credible non-Meta C + source-backed Atlas/Time Machine + authenticated inspector + strong video.
2. **Silver:** real Meta + protected fair A/B + trustworthy source-backed evidence + excellent clear demo.
3. **Bronze:** real Meta + one **approved** actual agent outcome + protected Verify and honest no-causal-claim UI.
4. **Minimum truthful:** real eligible Meta + source-backed recommendations + functioning booking fixture + existing **no-inference** protected grader + transparent "agent experiment not yet run"; no inflated claims.
5. **Blocked eligibility/Meta:** do not assert qualifying Meta use or eligible submission. Resolve official rules/provider access rather than fabricate.

**No feature may cross from lower to higher tier through simulated results.** A losing comparison can still be Gold/Silver if it is rigorous, informative and explained truthfully.
