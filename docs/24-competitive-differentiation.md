# 24 — What makes Forecode different?

A conventional reviewer judges code at rest; a linter checks known rules; an agent evaluator asks whether a current task passed. Forecode explicitly tests **architecture against future change** informed by confirmed developer goals, using Meta proposals as hypotheses and Verify as an independent measurement boundary.

Novelty is **conditional and evidence-based**: a counterfactual architecture certificate connecting a human intent → architectural alternative → challenge scenario → real isolated rollout → trusted outcome. Prior work exists for every underlying technique.

Do not oversell 'chess engine' or 'zero audit'. Meta's contribution must be quantified by an ablation before claiming it beats templated futures or a good AGENTS.md.
