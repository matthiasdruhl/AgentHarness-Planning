# Codex workflow

1. Verify official organizer terms before app creation. 2. Read README, AGENTS, docs/21, relevant ticket and contracts. 3. Implement one ticket in separate app repo. 4. Run existing test scripts; document command and **actual** exit code. 5. Record hashes/fixtures and model use. 6. Update checklists and next dependency; no invented progress. 7. Keep any experiment runner local and fail closed unless isolation verified.

Change protocol: update docs/17 ADR, contracts, tests, task board, demo caveats together when scope changes. Never merge old Verify PR without a semantic conflict review. Feature freeze Nov 2.
