## Minimum automated/manual tests

- Clean judge browser uses read-only hosted demo without credentials and follows links; accessible labels, keyboard and readable video.
- Meta mock/real/error/quota/offline states label provider and live vs recorded correctly; unconsented text never sent.
- Rejected or changed intention invalidates dependent results; unknown candidate/reference and executable operation rejected.
- Actual trusted failure -> REJECTED; absent, forged, stale or invalid check -> INSUFFICIENT_EVIDENCE; required fresh trusted passes -> scoped VERIFIED.
- Agent-modified visible tests cannot affect independent oracle; never expose hidden tests, host secrets or arbitrary shell endpoint.
- Every measured claim has original run ID, evidence SHA and check ID; cost/tokens missing remains unknown rather than zero.
- Source, video and certificate agree; reports include losing/inconclusive runs and B upfront cost.
- If no safe experiment exists, clearly state **no validated architecture improvement**; do not substitute fake run statistics.
