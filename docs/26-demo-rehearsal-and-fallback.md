# 26 — Demo rehearsal and failure recovery

Primary script: [DEMO_SCENARIO.md](DEMO_SCENARIO.md) and [15 storyboard](15-demo-and-submission.md). Record 2–3 minute target **subject to final organizer rules**.

## Speaker notes
**Hook:** “The assistant says the fix is complete. The test trace says otherwise.”
**Inspect:** show exact nonzero test exit status and the subsequent contradictory final message; point to immutable event IDs.
**Meta moment:** user explicitly runs Muse analysis; identify model and response provenance. A diagnosis is a hypothesis until grounded in evidence.
**Test moment:** demonstrate supported closed DSL candidate, baseline FAIL, one approved guard and policy PASS; repeat “the source test still fails; we prevented a false success claim.”
**Final:** export evidence and precise limitations. No claim of arbitrary agent replay, real patch, production safety certification or benchmark superiority.

## Contingencies
| Failure | Immediate safe presentation | What not to claim |
|---|---|---|
| Meta key absent or API outage/429 | Continue deterministic fixture timeline, checks, scripted replay/export. Show prominently **RECORDED DEMO** if a saved inference is displayed. | Never call recorded output live |
| Model JSON invalid / nonexistent event IDs | Show validation warning and deterministic findings; optionally use clearly labeled recorded fallback. | Never quietly repair unsupported evidence into verified result |
| Deployed site down | Use locally verified build / prerecorded full walkthrough, explicitly labeled; include app outage limitation | Don't state public URL currently works |
| Unsupported imported trace for replay | Explain analyze-only behavior, switch to bundled fixture with verified manifest | Don't imply external code executed |
| Guard doesn't demonstrate expected outcome | Stop showing success claim; present failed assertion/evidence and contingency video | Don't swap fixture mid-run and imply continuity |
| Credits exhausted/public abuse concern | Disable public model route and use offline path | Don't run unlimited retries or expose key |
| Demo video upload fails | Follow organizer accepted format/backup route; preserve evidence and submit before actual deadline | Don't assume unverified link is accepted |

## Rehearsal signoff (implementation period)
- [ ] Hero path completes without Meta inference.
- [ ] One **real** Meta analysis succeeded under verified credit budget; record request metadata.
- [ ] Evidence links focus correct events; no missing IDs.
- [ ] Guard PASS clearly distinguished from still-failed test.
- [ ] Replay deterministic across five runs; exported report includes provenance.
- [ ] Rehearse API timeout, invalid response, mobile/browser and incognito production.
- [ ] Capture uninterrupted demo recording plus separately labeled offline backup.
- [ ] Judge Q&A in [24](24-competitive-differentiation.md) practiced; no false claims.
- [ ] Verify final organizer video duration, file type and form fields.
