# Submission checklist

- [ ] Official organizer requirements, accepted track and deadline verified.
- [ ] All used source/assets/models permitted; licensing and attribution included.
- [ ] Live judge-access URL or reproducible instructions work from clean session.
- [ ] No user-supplied arbitrary code execution on public deploy.
- [ ] Meta evidence real and model endpoint access verified; fallback labeled.
- [ ] P0 demo steps reproduce with actual controlled fixtures.
- [ ] Every score/token/cost/regression number linked to measured run or explicitly estimated.
- [ ] Architecture certificate includes upfront cost, unknowns and adverse outcomes.
- [ ] Held-out task frozen before candidate selection.
- [ ] Build, typecheck, tests and E2E actually executed and results recorded.
- [ ] Video length/format per organizer portal, readable split-screen.
- [ ] Source and demo links visible with no credentials; no hidden oracle leak.
- [ ] Submission confirmation captured before deadline.
