## Optional interpretation and release limits

Meta generates hypotheses, directional predictions and a proposed challenge; a coding agent is a controlled implementation instrument; the protected evaluator checks exact outputs; ForeCode orchestrates and presents evidence. No component's role can supply another's missing proof. Optional Meta interpretation needs genuine prospective issuance/enrollment and a separately authorized sanitized evidence summary. It was not called in PR48 and is unprovisioned in the reviewed production composition. Omit it from the 180-second default.

Historical knowledge/design exposure and shared owner-AI custody limit independence. Report those limitations if a future result is admitted. Do not rewrite the recorded prediction to align with later metric instrumentation. Freeze the counting rule prospectively for any new study, or abstain from that metric claim.
