## Claim and screen controls

- Keep visible labels for **recorded Meta reasoning**, **proposal**, **modeled estimate**, **recorded protected outcome**, **not run**, **unknown**, and **inconclusive**, as applicable. A replay's conceptual stages do not establish a common execution clock.
- The cancellation bypass is a **proposed counterexample**, not an observed vulnerability. Permission delegation remains a future requirement in the baseline fixture.
- Source-backed baseline diagrams and proposed B boundaries are distinct from observed final topology. Static trace animation is not a source diff or measured architecture effect.
- A passing CI suite or harmless sandbox control is software/operational evidence, never proof of a completed architecture tournament.
- A valid A/B can support a bounded architecture comparison. Meta incremental benefit needs a separate equally informed non-Meta control. Protected evaluator independence from the coding workspace is narrower than human/organizational/blind independence.
- Exact public projection disclosure and optional provider-summary disclosure are separate permissions. This assignment grants neither. Never inspect private outcomes merely to improve the script.
