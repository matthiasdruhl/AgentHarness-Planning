### Contract Freeze v1 evaluator gate
Use `CheckResultV1`, `EvaluatorReceiptV1`, `VerificationV1` and `CertificateV1` literal schema definitions from [machine catalog](../contracts/schemas/forecode-v1.schema.json). The [semantic contract](../docs/CONTRACT-FREEZE-v1.md) requires **protected** receipt custody, post-agent source-tree/test-suite/evaluator/policy identity, canonical result digest and non-self-referential JCS hashes. Test forged/stale/missing evidence, swapped run, required fail precedence, untrusted preview insufficiency, and server artifact loader authority. An agent self-report or digest pasted into a request cannot mint VERIFIED.
